# 👩🏼‍💻 Kodakademin

## 🧾 Beskrivning

Detta repository innehåller projektarbetet i kursen programmering i TypeScript som är en del av webbutvecklingsprogrammet på Mittuniversitetet i Sundsvall. 

Uppgiften går ut att skapa en webbplats för ett fiktigt universitet eller högskola, där det ska gå att lista tillgängliga kurser - samt kunna skapa ett eget ramschema av en upppsättning kurser.

---

# 🎯 Syfte

Syftet med projektet är att omsätta kunskaper från de tidigare momenten i praktiken och i ett större sammanhängande projekt, där tidigare moment i kursen ingår med TypeScript-programmering och Angular som ramverk.
